# Factorielle Récursive

## Description
Calcule la factorielle d'un entier positif $n$ par récursivité via `FactorielRec(n: Entier) : Entier`, en utilisant la relation $n! = n \times (n - 1)!$ avec le cas de base $0! = 1! = 1$.

## Concepts Abordés
- Récursivité directe (`FactorielRec`)
- Cas de base (`n <= 1`) et appel récursif (`n - 1`)
- Structure conditionnelle `Si ... Alors ... Sinon`
