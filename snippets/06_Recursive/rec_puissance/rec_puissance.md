# Puissance Récursive

## Description
Calcule $x^n$ par récursivité à l'aide de `PuissanceRec(x: Réel, n: Entier) : Réel`, en appliquant $x^n = x \times x^{n - 1}$ avec le cas de base $x^0 = 1$.

## Concepts Abordés
- Récursivité sur l'exposant `n`
- Cas de base (`n = 0`)
- Appels récursifs imbriqués
